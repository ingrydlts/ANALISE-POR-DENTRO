Painel de Atualização de Métricas → GitHub

1. Conexão com o GitHub não configurado

Preencha uma vez — fica salvo só neste navegador (localStorage), nunca é enviado a lugar nenhum além da API do GitHub.

2. Upload das métricas do mês (ciclo de performance)

Aceita: export CSV do YouTube Studio / Instagram Insights, um JSON já pronto (um ciclo ou o insights.json completo), ou um HTML salvo de uma página de métricas.
📂 Clique para escolher um arquivo (.json, .csv, .html)

3. Revisar antes de publicar

Tudo pré-preenchido pelo upload pode ser corrigido aqui. Nada é publicado sem você conferir.
▶ YouTube
◎ Instagram
Avançado — dados diários, métricas calculadas, campos extras (JSON bruto)
Preserva campos que não têm formulário dedicado (ex: dados_diarios, metricas_calculadas, audiencia). O que não for tocado aqui é herdado do ciclo anterior/upload.

4. Outros módulos

Concorrência e Audiência normalmente chegam sozinhos via GitHub Actions (scripts/analyze_concorrencia.py e analyze_audiencia.py). Use aqui para publicar manualmente, ou para Boas Práticas / Calendário / Canais monitorados, que ainda não têm automação.
Cole um objeto JSON de um ciclo de concorrencia. Se já existir uma entrada com o mesmo id, ela é substituída (upsert) — não duplica.
Cole um objeto JSON de um ciclo de boas_praticas. Upsert por id.
Cole um objeto JSON de um mês de calendario. Upsert por id.
Substitui o conteúdo inteiro de canais.json (arquivo separado do insights.json). Busca a versão atual do repositório antes de publicar — carregue primeiro para não perder o que já existe.
